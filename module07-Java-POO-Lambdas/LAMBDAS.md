## ⚡ **LAMBDAS E INTERFACES FUNCIONAIS**

Os exercícios trabalham com expressões lambda, referências de método e interfaces funcionais presentes no Java.

### 📋 Mini Challenge - Lambdas
Implementa diversos exemplos utilizando **Consumer**, **Supplier**, **Function** e **UnaryOperator**.
Trabalha com divisão de Strings, processamento de caracteres, reutilização de funções e simplificação de código através de Expressões Lambda.
**Localização:** `praticas/MiniChallenge.java`

### 📋 Method Reference
Demonstra o uso de **Method References** como alternativa às Expressões Lambda,
tornando o código mais limpo e legível em situações onde apenas um método existente precisa ser referenciado.
**Localização:** `praticas/methodreference/`

## 💡 Conceitos-Chave Aprendidos

**Expressões Lambda:** Aprendi a substituir classes anônimas por uma sintaxe muito mais simples, reduzindo a quantidade de código e deixando as implementações mais legíveis.

**Interfaces Funcionais:** Descobri como utilizar interfaces que possuem apenas um método abstrato, permitindo implementar comportamentos utilizando Expressões Lambda.

**java.util.function:** Trabalhei com as principais interfaces funcionais do Java, como **Consumer**, **Supplier**, **Function** e **UnaryOperator**, entendendo quando utilizar cada uma.

**Method References:** Aprendi a utilizar referências de método para tornar o código ainda mais conciso quando uma expressão lambda apenas chama um método existente.

**Boas Práticas:** Procurei escrever código mais limpo, reutilizável e legível, evitando duplicação e aproveitando os recursos funcionais disponíveis na linguagem.

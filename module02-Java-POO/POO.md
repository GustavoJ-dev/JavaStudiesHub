# ☕Module 02 — Programação Orientada a Objetos (POO):

Este módulo representa meu aprofundamento na Programação Orientada a Objetos (POO) em Java.
Aqui estão reunidos os conceitos fundamentais da POO, que transformam o desenvolvimento em Java
em uma abordagem mais organizada, modular e reutilizável.

O objetivo deste módulo é dominar os pilares da POO: encapsulamento, herança, polimorfismo
e abstração, preparando o terreno para conceitos mais avançados como ‘Interfaces’, Generics,
Nested Classes e o uso de Collections.

# 🚀 Conteúdo Abordado

## 🔹 Conceitos Básicos da POO
- Classes e Objetos.
- Diferença entre classe e instância.
- Atributos e métodos.
- Construtor (constructor).
- Modificadores de acesso (`public`, `private`, `protected`, `default`).

## 🔹 Encapsulamento
- Princípio de encapsulamento.
- Modificadores de acesso.
- Métodos `getter` e `setter`.
- Ocultamento de dados (data hiding).
- Validação através de `setters`.

## 🔹 Herança (Inheritance)
- Classe pai (superclasse) e classe filha (subclasse).
- Palavra-chave `extends`.
- Reutilização de código através da herança.
- Sobrescrita de métodos (`@Override`).
- Método `super`.
- Hierarquia de classes.

## 🔹 Polimorfismo
- Polimorfismo em tempo de compilação (sobrecarga).
- Polimorfismo em tempo de execução (sobrescrita).
- Referências de tipos diferentes para objetos similares.
- Casting de objetos.
- Comportamento polimórfico.


## 🔹 Construtores e Inicialização
- Construtor padrão.
- Construtores com parâmetros.
- Sobrecarga de construtores.
- Inicialização de atributos.
- Construtor da superclasse.

# 🧩 Exercícios e Desafios

Este módulo contém diversos desafios práticos voltados para consolidar os conceitos de POO.

Entre os principais exercícios desenvolvidos estão:

- Criação de classes com atributos e métodos.
- Encapsulamento com `private` e `public`.
- Herança com classes pai e filha usando `extends`.
- Sobrescrita de métodos em classes derivadas com `@Override`.
- Polimorfismo com referências de superclasse apontando para subclasses.
- Método `super` para acessar comportamento da classe pai.
- Hierarquias de classes com múltiplos níveis.
- Casting de objetos para tipos específicos.
- Validação de dados através de encapsulamento.
- Reutilização de código através de herança.
- Projetos práticos como "Burger Joint" integrando herança e polimorfismo.

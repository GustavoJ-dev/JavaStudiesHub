<h2 style="color:#5382A1;">📦 Module 05 — Generics:</h2>

<p style="font-size:18px;">

  tipadas e soluções escaláveis</strong>, seguindo as boas práticas do desenvolvimento Java moderno.
</p>

**Saiba mais sobre o módulo em:** [module05-Java-POO-Generics/GENERICS.md](module05-Java-POO-Generics/GENERICS.md)

</p>

<h2 style="color:#5382A1;">🗄️ Module 15 — Java JDBC:</h2>

<p style="font-size:15px;">

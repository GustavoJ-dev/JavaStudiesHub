# 📚 Module 11 - Core

Bem-vindo ao **Módulo 11: Core**!

Este módulo aprofunda a moderna API de datas e horas introduzida no Java 8,
**java.time**, explorando seus principais recursos para manipulação de datas,
horários, fusos horários e internacionalização. Durante os estudos são abordadas
as principais classes da API, permitindo desenvolver aplicações mais seguras,
legíveis e eficientes para o tratamento de informações temporais.

Além dos conceitos fundamentais, o módulo apresenta um projeto prático que utiliza
**Streams**, **DateTimeFormatter**, **ZoneId**, **ZonedDateTime** e
**Locale** para organizar reuniões entre pessoas localizadas em diferentes
fusos horários.

# 📅 **JAVA DATE AND TIME API**

Os exercícios desta seção exploram os principais recursos da API moderna de datas
e horas do Java, demonstrando como criar, manipular, converter e formatar datas
e horários de forma segura e eficiente.

### 🌎 Employee Meeting Scheduler

Sistema de agendamento de reuniões entre funcionários localizados em diferentes
países e fusos horários.

**Conceitos:**

- LocalDate
- LocalTime
- LocalDateTime
- ZonedDateTime
- ZoneId
- ZoneRules
- Duration
- DateTimeFormatter
- Locale
- Streams API

**Localização:** `praticas/employeereunion/`

## 💡 Conceitos-Chave Aprendidos

**Java Date and Time API:** Aprendi a utilizar a moderna API de datas e horas do Java, substituindo as antigas classes
por uma solução mais segura, imutável e intuitiva.

**Datas e Horários:** Compreendi como trabalhar com **LocalDate**, **LocalTime** e **LocalDateTime** para representar 
datas, horários e momentos específicos.

**Fusos Horários:** Aprendi a utilizar **ZoneId**, **ZoneRules** e **ZonedDateTime** para representar horários em 
diferentes regiões do mundo e converter datas entre fusos horários.

**Formatação:** Aprofundei o uso do **DateTimeFormatter** para apresentar datas e horários em diferentes formatos e 
idiomas utilizando **Locale**.

**Períodos e Durações:** Utilizei **Period** e **Duration** para calcular diferenças entre datas e horários com
precisão.

**Boas Práticas:** Procurei utilizar classes imutáveis, internacionalização e recursos modernos da linguagem para 
desenvolver aplicações mais confiáveis e fáceis de manter.

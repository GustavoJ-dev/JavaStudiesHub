### 📚 Module 06 - Classes Aninhadas (Nested Classes) em Java

Bem-vindo ao **Módulo 06: Classes Aninhadas (Nested Classes)**!

Este módulo aprofunda um recurso importante da Programação Orientada a Objetos em Java:
**Nested Classes** (Classes Aninhadas).
Aprendendo a organizar melhor o código, encapsular comportamentos relacionados e utilizar
**Static Nested Classes**, **Inner Classes** e **Local Classes** em cenários reais.

---

## 🎯 Objetivos do Módulo

O que será possível com este módulo:

✅ Compreender os diferentes tipos de **Nested Classes**  
✅ Criar **Static Nested Classes**  
✅ Utilizar **Inner Classes** para encapsular comportamentos internos  
✅ Trabalhar com **Local Classes** dentro de métodos  
✅ Melhorar a organização e encapsulamento do código  
✅ Aplicar Nested Classes em projetos práticos  
✅ Desenvolver aplicações utilizando classes internas de forma reutilizável

## 💡 Conceitos-Chave Aprendidos

**Static Nested Classes:** Aprendi quando utilizar uma classe estática dentro de outra para agrupar responsabilidades relacionadas sem depender de uma instância da classe externa.

**Inner Classes:** Entendi como classes internas podem acessar diretamente os membros da classe externa, facilitando o encapsulamento de comportamentos específicos.

**Local Classes:** Descobri como declarar classes dentro de métodos para representar comportamentos temporários e restritos ao escopo da operação.

**Boas Práticas:** Organizei melhor o código utilizando classes relacionadas no mesmo arquivo quando fazia sentido. Mantive encapsulamento, reutilização de código, separação de responsabilidades e nomes claros para facilitar manutenção.

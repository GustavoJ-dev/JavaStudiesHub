# Módulo 01: Primeiros Passos em Java

Este módulo é a minha porta de entrada para o mundo da programação Java. 
Aqui, são abordados os conceitos fundamentais para quem está começando,
desde a configuração do ambiente até a escrita dos primeiros programas.

## 🚀 Conteúdo Abordado

### 1. Content (Teoria e Apresentação)
- **`Primeiros-Passos-em-Java.pptx`**: Material de apoio que introduz a linguagem Java, seu ecossistema, JVM, 
    JRE, JDK e a estrutura básica de um programa.

### 2. Learning (Prática e Desafios Resolvidos)
- **`HelloWorld.java`**: O tradicional "Olá, Mundo!" que marca o início da jornada. 
    Demonstra a estrutura básica de uma classe, o método `main` e a saída de dados no console, incluindo a impressão de variáveis de diferentes tipos.
- **`TiposPrimitivos.java`**: Exploração dos tipos de dados primitivos em Java (int, long, byte, short, 
  float, double, boolean, char). Apresenta seus intervalos de valores e
  a relação com suas classes Wrapper correspondentes.
- **`ExpressionsCasting.java`**: Foca em como Java lida com expressões aritméticas e lógicas, 
  além de demonstrar o conceito de Type Casting (conversão de tipos), tanto implícita quanto explícita.

## 🧠 O que Aprendi

Neste módulo fundamental, os principais aprendizados foram:

1.  **Configuração do Ambiente**: Entendimento e instalação do JDK.
2.  **Estrutura Básica de um Programa Java**: Como classes e métodos `main` funcionam.
3.  **Saída de Dados**: Utilização do `System.out.println()` para exibir informações.
4.  **Tipos de Dados Primitivos**: Compreensão dos diferentes tipos para armazenar números, caracteres e 
     valores booleanos, e seus limites.
5.  **Variáveis e Expressões**: Declaração de variáveis e execução de operações básicas.
6.  **Type Casting**: Como converter um tipo de dado para outro, evitando perdas de informação ou erros.

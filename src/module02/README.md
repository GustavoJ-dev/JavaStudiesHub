# Módulo 02: IntelliJ e Lógica Condicional

Este módulo foca na utilização da IDE IntelliJ IDEA para otimizar o desenvolvimento e no estudo aprofundado 
da lógica condicional e operadores lógicos e aritméticos em Java.

## 🚀 Conteúdo Abordado

### 1. Content (Teoria e Apresentação)
- **`IntelliJ-e-Logica-Condicional.pptx`**: Material que apresenta as funcionalidades da IDE e
  os conceitos fundamentais de controle de fluxo condicional em Java (`if`, `else`, `else if`).

### 2. Learning (Prática e Desafios Resolvidos)
- **`ChallengeOne.java`**: Um desafio prático que consolida o conhecimento sobre:
    - Uso de variáveis do tipo `double`.
    - Operações aritméticas combinadas (adição e multiplicação).
    - Operador de módulo (`%`) para encontrar o resto de uma divisão.
    - Estruturas de controle `if-else` para tomada de decisão baseada nos resultados dos cálculos.

## 🧠 O que Aprendi

Neste módulo intermediário-inicial, os principais aprendizados foram:

1.  **Produtividade com IntelliJ**: Como utilizar a IDE para facilitar a escrita e o teste de programas Java.
2.  **Lógica Condicional**: Como controlar o fluxo do programa através de condições.
3.  **Operadores Lógicos e Relacionais**: Uso de operadores como `==`, `!=`, `<`, `>`, `<=`, `>=` e o operador de resto `%`.
4.  **Resolução de Problemas**: Aplicação prática de cálculos matemáticos básicos para resolver um desafio lógico e exibir o resultado correspondente.
5.  **Boas Práticas de Codificação**: A importância de organizar o código de forma clara e utilizar documentação (Javadoc) 
    para explicar a lógica.

---
*Este módulo prepara o desenvolvedor para lidar com programas mais complexos que exigem tomada de decisão dinâmica.*

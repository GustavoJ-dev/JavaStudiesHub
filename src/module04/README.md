# Módulo 04: Controle de Fluxo e Lógica de Programação

Este módulo aprofunda o conhecimento em estruturas de controle de fluxo, 
essenciais para criar programas que executam ações repetitivas e tomam 
decisões complexas. Exploramos loops (`for`, `while`) e `switch expressions` 
de forma prática.

## 🚀 Conteúdo Abordado

### 1. Content (Teoria e Apresentação)
- **`package-info.java`**: Documentação do pacote teórico do módulo.

### 2. Learning (Prática e Desafios Resolvidos)
Este pacote contém uma série de exercícios práticos que abordam:

- **`challenge13/ExerciseThirteen.java`**: Conversão de dígitos numéricos 
  para texto em português usando `switch expression`.
- **`challenge14/ExerciseFourteen.java`**: Cálculo de dias em um mês, 
  considerando anos bissextos e `switch expression`.
- **`challenge15/ExerciseFifteen.java`**: Soma de números ímpares em um 
  intervalo usando loop `for` e validação.
- **`challenge16/ExerciseSixteen.java`**: Verificação de números palíndromos 
  com loop `while`.
- **`challenge17/ExerciseSeventeen.java`**: Soma do primeiro e último dígito 
  de um número.
- **`challenge18/ExerciseEighteen.java`**: Soma de dígitos pares de um número.
- **`challenge19/ExerciseNineteen.java`**: Verificação de dígitos compartilhados 
  entre dois números de dois dígitos.
- **`challenge20/ExerciseTwenty.java`**: Verificação de último dígito comum 
  entre três números.
- **`challenge21/ExerciseTwentyOne.java`**: Impressão de todos os fatores 
  positivos de um número.
- **`challenge22/ExerciseTwentyTwo.java`**: Cálculo do Maior Divisor Comum (MDC) 
  usando o algoritmo de Euclides.
- **`challenge23/ExerciseTwentyThree.java`**: Verificação de Números Perfeitos.
- **`challenge24/ExerciseTwentyFour.java`**: Conversão de números para palavras 
  em inglês, incluindo manipulação de dígitos.
- **`challenge25/ExerciseTwentyFive.java`**: Lógica para empacotamento de farinha 
  com sacos de diferentes pesos.
- **`challenge26/ExerciseTwentySix.java`**: Encontrar o maior fator primo de um número.
- **`challenge27/ExerciseTwentySeven.java`**: Impressão de um padrão de estrela 
  em formato de quadrado com bordas e diagonais.
- **`challenge28/ExerciseTwentyEight.java`**: Leitura de entrada do usuário, 
  cálculo de soma e média, e tratamento de erros.
- **`challenge29/ExerciseTwentyNine.java`**: Cálculo de baldes de tinta 
  necessários, com sobrecarga de métodos para diferentes cenários.

## 🧠 O que Aprendi

Neste módulo, os principais aprendizados foram:

1.  **Loops (`for`, `while`)**: Utilização eficaz para repetição de tarefas.
2.  **`switch expressions`**: Uma forma moderna e concisa de lidar com 
    múltiplas condições.
3.  **Manipulação de Dígitos**: Extração e processamento de dígitos de 
    números inteiros.
4.  **Lógica de Negócio Complexa**: Resolução de problemas que exigem 
    múltiplas condições e cálculos.
5.  **Validação de Entrada**: Implementação robusta de verificações para 
    garantir a integridade dos dados.
6.  **Modularização e Reutilização**: Criação de métodos auxiliares e 
    sobrecarga para tornar o código mais limpo e eficiente.

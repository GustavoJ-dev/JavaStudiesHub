# Módulo 03: Lógica Condicional Avançada e Métodos

Este módulo aprofunda o estudo da lógica de programação em Java, 
focando na criação e utilização de métodos, estruturas condicionais 
complexas e validação de entrada. É um passo crucial para escrever 
código mais modular e reutilizável.

## 🚀 Conteúdo Abordado

### 1. Content (Teoria e Apresentação)
- **`package-info.java`**: Documentação do pacote teórico do módulo.

### 2. Learning (Prática e Desafios Resolvidos)
Este pacote contém uma série de exercícios práticos que abordam:

- **`challenge1/ExerciseOne.java`**: Verificação de números negativos 
  com operador ternário.

- **`challenge2/ExerciseTwo.java`**: Conversão de km/h para mi/h, 
  demonstrando sobrecarga de métodos e validação.

- **`challenge3/ExerciseThree.java`**: Conversão de Kilobytes para 
  Megabytes e Kilobytes restantes.

- **`challenge4/ExerciseFour.java`**: Lógica condicional para verificar 
  horário de latido de cachorro.

- **`challenge5/ExerciseFive.java`**: Determinação de ano bissexto 
  com regras de divisibilidade.

- **`challenge6/ExerciseSix.java`**: Comparação de números de ponto 
  flutuante com precisão de três casas decimais.

- **`challenge7/ExerciseSeven.java`**: Verificação se a soma de dois 
  números é igual a um terceiro.

- **`challenge8/ExerciseEight.java`**: Verificação de idade adolescente 
  (`isTeen`) e se um grupo contém adolescentes (`hasTeen`).

- **`challenge9/ExerciseNine.java`**: Cálculo de área de círculo e 
  retângulo, exemplificando sobrecarga de métodos.

- **`challenge10/ExerciseTen.java`**: Conversão de minutos para anos e dias.

- **`challenge11/ExerciseEleven.java`**: Comparação de três números 
  (todos iguais, todos diferentes, ou misto).

- **`challenge12/ExerciseTwelve.java`**: Lógica para determinar se um 
  gato está brincando com base na temperatura e estação.

- **`extrachallenges/ExtraOne.java`**: Cálculo e exibição de posições 
  em um placar de alta pontuação.

- **`extrachallenges/ExtraTwo.java`**: Conversão de segundos/minutos 
  para formato de tempo legível, com sobrecarga.

## 🧠 O que Aprendi

Neste módulo, os principais aprendizados foram:

1.  **Criação e Uso de Métodos**: Como encapsular lógica em funções 
    reutilizáveis.
2.  **Sobrecarga de Métodos (Method Overloading)**: Definir múltiplos 
    métodos com o mesmo nome, mas diferentes parâmetros.
3.  **Lógica Condicional Avançada**: Uso eficaz de `if-else if-else`, 
    operadores lógicos (`&&`, `||`) e ternários.
4.  **Validação de Entrada**: Implementar verificações para garantir 
    que os métodos recebam dados válidos.
5.  **Modularização do Código**: Organizar o código em métodos menores 
    e mais gerenciáveis para melhor legibilidade e manutenção.
6.  **Tipos de Retorno e Parâmetros**: Compreensão de como passar 
    informações para e de métodos.

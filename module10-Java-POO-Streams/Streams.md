# 📚 Module 10 - Streams API em Java

Bem-vindo ao **Módulo 10: Streams API**!

Este módulo aprofunda um dos recursos mais poderosos do Java moderno: a
**Streams API**. Ao longo dos estudos são exploradas operações funcionais para
processamento de coleções, permitindo escrever código mais declarativo, conciso
e eficiente utilizando pipelines de operações.

Além dos conceitos fundamentais, este módulo reúne diversos exercícios e projetos
práticos utilizando **Streams**, **Collectors**, **Optional** e operações de
agregação para filtrar, transformar, agrupar e analisar dados de forma elegante.

---

## 🎯 Objetivos do Módulo

O que será possível com este módulo:

✅ Compreender o funcionamento da **Streams API**

✅ Criar pipelines utilizando operações intermediárias e terminais

✅ Trabalhar com **filter**, **map**, **flatMap**, **sorted** e **distinct**

✅ Utilizar **Collectors** para agrupar, particionar e coletar dados

✅ Aplicar **Optional** para tratar ausência de valores com segurança

✅ Gerar estatísticas utilizando Streams

✅ Desenvolver aplicações utilizando programação funcional em Java

# 💡 Conceitos-Chave Aprendidos

**Streams API:** Aprendi a processar coleções utilizando pipelines compostos por operações intermediárias e terminais, 
deixando o código mais declarativo, legível e reutilizável.

**Operações de Stream:** Compreendi quando utilizar operações como **filter**, **map**, **flatMap**, **sorted**, 
**distinct** e **reduce** para transformar e analisar dados.

**Collectors:** Aprofundei o uso da classe **Collectors** para agrupar, particionar, resumir e coletar informações em 
diferentes estruturas de dados.

**Optional:** Aprendi a utilizar **Optional** para tratar valores ausentes de maneira segura, evitando verificações 
desnecessárias e reduzindo o risco de `NullPointerException`.

**Estatísticas:** Utilizei operações como **summaryStatistics**, **count**, **average**, **min**, **max** e **counting**
para gerar informações estatísticas sobre grandes conjuntos de dados.

**Boas Práticas:** Procurei escrever código mais limpo, expressivo e eficiente, aplicando os princípios da programação 
funcional juntamente com Programação Orientada a Objetos.

# 💡 Conceitos-Chave Aprendidos

**Streams API:** Aprendi a processar coleções utilizando pipelines compostos por operações intermediárias e terminais, 
deixando o código mais declarativo, legível e reutilizável.

**Operações de Stream:** Compreendi quando utilizar operações como **filter**, **map**, **flatMap**, **sorted**, 
**distinct** e **reduce** para transformar e analisar dados.

**Collectors:** Aprofundei o uso da classe **Collectors** para agrupar, particionar, resumir e coletar informações em 
diferentes estruturas de dados.

**Optional:** Aprendi a utilizar **Optional** para tratar valores ausentes de maneira segura, evitando verificações 
desnecessárias e reduzindo o risco de `NullPointerException`.

**Estatísticas:** Utilizei operações como **summaryStatistics**, **count**, **average**, **min**, **max** e **counting**
para gerar informações estatísticas sobre grandes conjuntos de dados.

**Boas Práticas:** Procurei escrever código mais limpo, expressivo e eficiente, aplicando os princípios da programação 
funcional juntamente com Programação Orientada a Objetos.

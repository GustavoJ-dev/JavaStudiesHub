# 📚 Module 08 - Collections Framework em Java

Bem-vindo ao **Módulo 08: Collections Framework**!

Este módulo aprofunda uma das bibliotecas mais importantes da linguagem Java: o
**Java Collections Framework**. Ao longo dos estudos são exploradas as principais
estruturas de dados da API de Collections, compreendendo suas características,
diferenças de desempenho e aplicações em cenários reais.

Além dos conceitos fundamentais, este módulo reúne diversos exercícios e projetos
práticos utilizando **List**, **Set** e **Map**, aplicando Programação Orientada
a Objetos juntamente com algoritmos de ordenação, busca e navegação em coleções.

---

## 🎯 Objetivos do Módulo

O que será possível com este módulo:

✅ Compreender a arquitetura do **Collections Framework**

✅ Trabalhar com **List**, **Set** e **Map**

✅ Comparar implementações como **ArrayList**, **HashSet**, **TreeSet**, **HashMap** e **TreeMap**

✅ Aplicar **Comparable** e **Comparator**

✅ Utilizar algoritmos de busca e ordenação

✅ Desenvolver aplicações utilizando estruturas de dados adequadas

✅ Consolidar boas práticas de Programação Orientada a Objetos utilizando Collections

## 💡 Conceitos-Chave Aprendidos

**Collections Framework:** Aprendi como a biblioteca de coleções do Java fornece estruturas reutilizáveis para armazenar, pesquisar, ordenar e manipular objetos de forma eficiente.

**Lists:** Compreendi quando utilizar listas para armazenar elementos ordenados, permitindo acesso por índice e manipulação dinâmica dos dados.

**Sets:** Entendi como conjuntos garantem unicidade dos elementos e como diferentes implementações oferecem estratégias distintas de ordenação e desempenho.

**Maps:** Aprendi a trabalhar com pares de chave e valor utilizando implementações como **HashMap**, **LinkedHashMap** e **TreeMap**.

**Comparable e Comparator:** Aprofundei os conhecimentos sobre ordenação natural e personalizada de objetos.

**Boas Práticas:** Procurei escolher a estrutura de dados mais adequada para cada problema, mantendo código organizado, reutilizável e de fácil manutenção.
